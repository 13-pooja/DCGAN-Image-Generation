## Aim
To implement a Deep Convolutional Generative Adversarial Network (DCGAN) to generate synthetic images using the MNIST dataset.

## Theory
DCGAN is a type of Generative Adversarial Network that uses convolutional neural networks. It consists of two main components:

- **Generator:** Generates synthetic images from random noise.
- **Discriminator:** Predicts whether an image is real or generated.

Both networks train against each other to improve the quality of generated images.

## Tools and Technologies
- Python
- PyTorch
- Google Colab
- MNIST dataset
- Matplotlib

## Methodology
1. Load and preprocess the MNIST dataset.
2. Define the Generator and Discriminator networks.
3. Configure the loss function and optimizers.
4. Train both networks.
5. Generate synthetic images.
6. Plot Generator and Discriminator loss curves.
